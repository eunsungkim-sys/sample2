sample2 테스트 웹페이지

배포 성공 이 페이지가 보이믴 커밋 → PR → 머지 → GitHub Actions → GitHub Pages 배포가 끝까지 동작한 것입니다.

이 페이지가 거쳐 온 길

  1. 밌랜치 feature/test-page에서 index.html 생성 후 커밋
  2. Pull request를 열어 main에 합치기 요청
  3. CI 워크플로(ci.yml)가 index.html과 <title> 존재를 검사
  4. Merge → static.yml이 자동 실행되어 GitHub Pages에 배포
